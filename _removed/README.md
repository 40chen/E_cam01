## 快门声（2026-09-19 移除）

拍照时播一声"咔"。**功能本身是好的，代码也是对的——问题是这颗喇叭放不出来。**

### 这里有什么

| 文件 | 是什么 |
| --- | --- |
| `main_ui/shutter_sound.c` / `.h` | 曾经编进固件的裸 PCM（16kHz / 16bit / 立体声，250ms，15988 字节） |
| `tools/gen_shutter_sound.py` | 从素材生成上面那个文件的脚本（WAV → 裸 PCM） |
| `tools/preview_shutter_body.py` | 生成几档不同"低中频强度"的试听文件，调音色用 |
| `tools/check_shutter_sound.py` | 把源素材和固件里的 PCM 分别导成 WAV，用来在电脑上对比试听 |
| `assets/quick-camera-click.mp3` | **原始素材**（用户最早给的那份） |
| `assets/quick-camera-click.pcm` | 16000 Hz / 16bit / 单声道 / 2525 帧 的裸 PCM，用户自己重采样的版本 |
| `assets/shutter-body-*.wav` | `preview_shutter_body.py` 生成的试听文件 |

这些素材**全部集中在本目录**，`assets/` 里现在只剩启动页那张 `logo.jpg`。

### 为什么移除

**核心原因：素材的能量分布和这颗小喇叭的频率响应对不上。**

实测频谱（1024 点 DFT 的能量占比）：

```
             源素材    固件里最终那版
  0-  250Hz   0.0%       0.0%
250-  500Hz   0.1%      82.5%   ← 补了 body 之后
500- 1000Hz   0.5%       8.1%
1000-2000Hz   4.7%       1.4%
2000-4000Hz  25.2%       5.5%
4000-8000Hz  28.4%       2.5%
8000-22050Hz 41.2%        —
```

原素材 **1kHz 以下只有 1.6% 的能量，九成在 2kHz 以上**。板载小喇叭 3–5kHz 以上
就滚降了，等于绝大部分能量落在它放不出来的频段。

**对照实验印证了这一点**：`Settings → Test Speaker` 放 440Hz 正弦非常清楚
（能量全在喇叭谐振点上），而快门声走同一套代码、同一条通路却几乎听不见。

补了低中频的"身体"（`shutter-body-0.30`，1kHz 以下提到 60%）之后在板子上
**仍然偏小**。最后又试过一次**把用户重采样的 PCM 原样搬进固件、不做任何处理**
（峰值 -3.6 dBFS、RMS -23.9 dBFS，比测试音低 16dB），仍然是同样的结果，
于是决定整个功能不做。

### 如果以后要重做，这几条别再试一遍

1. **I2S 通道必须在 `bsp_audio_init()` 里 `i2s_channel_enable()`。**
   这一点已经修好并保留在 `components/lckfb_bsp/lckfb_bsp.c` 里了，**不要删**——
   MP3 功能也要靠它。当初移植时把这一句删掉了（注释里还写着理由，而理由是错的），
   结果是 I2S 主时钟起不来、`i2s_channel_write()` 一个字节都排不进 DMA，
   症状极像硬件故障：ES8311 寄存器全对、功放也开着，就是没声音。
   官方参考实现在 `O:\Desktop\DIY\ESP32 参考项目\11-mp3_player`。

2. **内部 DMA RAM 很紧张。** 实测相机 + WiFi + LVGL 都跑起来之后，
   `heap_caps_malloc(96000, MALLOC_CAP_DMA)` 直接失败；16384 字节能拿到。
   **音频缓冲必须分块，一块一两万字节**，不能一次分配整段。MP3 播放同理。

3. **别指望用软件"修"喇叭的频响。** 提高音量、加大数字增益、换采样率都试过，
   对"放不出来的频段"无效——那是物理限制。真要重做，得换一个**低中频成分更足**
   的素材（比如真实相机快门那种带机身共振的"咔哒"），或者换喇叭。

4. **诊断手段留下两个现成的**：`Settings → Test Speaker`（验证整条音频通路），
   以及 `tools/check_shutter_sound.py`（把固件里的 PCM 导出来在电脑上听）。
   以后"没声音"先跑这两个，能立刻分清是通路问题还是素材问题。
